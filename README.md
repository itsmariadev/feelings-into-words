**Feelings into Words**

Feelings into Words is an interactive web application developed with vanilla HTML, CSS, and JavaScript, created to explore and translate untranslatable terms from various languages that describe deep emotional states.

---

### Objective

The main objective of the project is to give visual and conceptual space to complex emotions that often do not have a direct translation in a single word. The interface was designed to be minimalist, welcoming, and intuitive, allowing smooth navigation between the literal and human meanings of the terms.

### Design

The layout adopts a minimalist aesthetic, featuring a harmonious color palette where each hue represents a distinct emotional category (joy, love, fun, anxiety, and anger). The design focuses on readability and visual comfort, utilizing flexible units to ensure a consistent experience across different screen sizes.

### Features

- **Dual Meanings:** Interactive toggling between the human context and the literal meaning of each term.
- **Visual Categorization:** Identification of emotions through customized colored tags.
- **Adaptive Responsiveness:** Optimized layout for both desktops and mobile devices.

### The Story Behind This Project

There are three things that I really like: one is books, two is languages, and three... cats! As humans, we experience countless kinds of feelings, and I always thought: is there a name for this? 

Then, I found those names! Even though I think that words are just the surface (our emotion is bigger than that)—just like Eckhart Tolle once said: *"Words reduce reality to something the human mind can grasp, which isn't very much."*—somehow I find comfort in knowing that something indeed exists to describe these feelings.

If you are curious about that too, you are going to love it like I did.
